# HappyZero Website

A multi-page site built with Vite, React, React Router, and Tailwind CSS.

## Routes

- `/` — Home
- `/talent` — Talent
- `/academy` — Academy
- `/digital-qms` — Digital QMS
- `/services` — Services
- `/about` — About
- `/resources` — Resources
- `/contact` — Contact
- `/yoa` — YOA

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
